This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).
This application is an API testing tool, similar to Postman, designed to simplify the process of working with web services. It allows users to create and send HTTP requests, inspect responses, and debug APIs efficiently. In addition to testing endpoints, the app can automatically generate code snippets in multiple programming languages, making it easier to integrate requests directly into projects. The application also supports localization for English and Russian.

## Tech stack

- Next.js
- Typescript
- postman code generators
- React DOM
- React Hook Form
- Tailwindcss
- vitest
- Husky
- Prettier
- ESLint

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
